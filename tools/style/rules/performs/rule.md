# Performing

A comment is a procedure. Someone consults it mid-task to settle one question,
then stops reading. Each register below addresses a reader who came to enjoy
the prose.

| Register | Tell | Example that got cut |
|---|---|---|
| Novel | scene-setting, sensory detail | "at 2am, in an unfamiliar module" |
| Essay | the balanced, quotable aphorism | "A rarer synonym is a promise of extra meaning" |
| Pronouncement | a rule shaped to be repeated | "Comments are scalpels and not bludgeons" |
| Stage line | dramatic verb, inverted clause | "Only the first of these survives" |
| Headline | fragment with elided structure | "Same tells, different surface" |
| Management update | announces shape or process | "Two rules. The first governs..." |
| Seminar paper | nominalization where a verb works | "The bound on positive form" |

Read the line aloud, and if it sounds delivered, cut it. Every example above
came out of these files, so expect to find them.

Use the plainest exact verb. Reaching for "survives", "waits" or "lives" where
"is" works means the sentence is performing. Avoid ALL CAPS dramatic language
(LAWS, etc).

Humanity decides which one thing to explain, in the words you would use to a
colleague at a whiteboard. It never licenses a second sentence of warmth, an
apology, or a joke that ages badly.

    // The lock is held across the await. Reordering deadlocks with the reaper.
    // The lock, held fast across the await, is where deadlock waits.
    // A terminal that will not answer stty throws.

Line 1 states the hazard. Line 2 performs. Line 3 gives a technical concept a
will of its own.
