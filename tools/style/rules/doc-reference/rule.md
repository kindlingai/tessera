# Internal references

Remove references to a section number, open item or other point in an
internal document: `❡1`, `§23`, `Q43`, "open question 30". The reader of the
code does not have the document, and its numbering drifts. A link to GitHub or
another external issue tracker is fine.

In a manual, a link to another file in the repo is fine, since the reader has
the file: "See [GUIDE.md](GUIDE.md) for the environment".
