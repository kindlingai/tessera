# Live metaphor

Dead metaphors are fine, because nobody decodes them: "deadlock", "handshake",
"orphan". A live one makes the reader work out the comparison before they get
the fact. If the term has no plain alternative, it has stopped being a
metaphor. If it does have one, use the plain word.

"Blast radius" fails this. "Scope" says it, so "blast radius" is decoration.

A term defined in the code or in `GLOSSARY.md` is a term of art, however
vivid it sounds: "universe" for `MENTAT_UNIVERSE`, "flap", "fall-through".
