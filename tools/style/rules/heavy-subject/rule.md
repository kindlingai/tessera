# Heavy participle subject

When a noun and an "-ing" phrase form the subject, the reader holds several
words before the verb arrives. The shape also tends to make an inert thing the
actor.

    A line holding only `---` separates examples.
    Put `---` on its own line between examples.

The first makes the line the actor. The writer does the work, so the second
gives the instruction. Where no instruction fits, lead with the thing that acts:
"The loader reads the key first" for "A file containing the key is read first".

A short phrase that names a role is fine: "the thread holding the lock must
release it before the await". Nothing shorter says which thread.

The shape is too common in plain prose for a regex, so this rule has only a Jev
question.
