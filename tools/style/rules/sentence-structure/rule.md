# Sentence structure

- One idea per sentence, roughly 20 words maximum.
- Three sentences maximum per block. Past that, restructure the code.
- Active voice, simple tense. Present tense to describe the code's
  behaviour. See [agent-passive](../agent-passive/rule.md).
- Noun clusters of three words maximum. "default axis view fallback order"
  becomes "order for resolving a default axis view".
- Vertical list for more than two parallel items. List length comes from the
  domain.
