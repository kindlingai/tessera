# Commit messages

The same tells appear in commit messages. A commit body says why, and what a
reviewer would otherwise reconstruct. If it says what, the diff already said
it.

- No canned assurance ("all tests pass and the change follows existing
  conventions").
- No asserted preservation ("while preserving existing functionality"). Show
  the preserved behaviour or drop the claim.
- No prose restatement of the diff.
- No rule of three in the subject line.
