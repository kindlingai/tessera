# Echo clause

"the code that sets them", "the paths that replace them", "the rules that
read them". The clause ends on "them", so the reader goes back to find the
noun it means, and finds only the noun it started from.

Name the relation in plain words, or drop the clause:

    /// Crate names and the paths that replace them.
    /// Replacement paths, by crate name.

    // Weight views belong to the rules that read them.
    // The rule reading a weight owns its views.
