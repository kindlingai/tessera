# Chained clause

A sentence that makes one claim, then hangs a second claim off its object with
a comma and "which", "whose" or "who", chains A to B and B to C:

    # This builder serves the MLA group, whose spec keeps `tokens_per_state` at 1.
    # This builder serves the MLA group. That group's spec keeps
    # `tokens_per_state` at 1.

The reader holds B as the object of the first claim while it turns into the
subject of the second. Split the claims into two sentences, or lead with B.

A clause that only describes the object with "is" adds a property, so the
pattern skips it: "picks the first address, which is the fastest".
A "which" clause inside the subject is fine ("The config, which lists every
peer, is read first"). A "that" clause is fine too. It narrows the noun.
