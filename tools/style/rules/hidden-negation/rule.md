# Hidden negation

Some negations are shaped as positive claims. Both shapes below state what
does not happen, and both read as pronouncements.

## Verb with "no"

"breaks no rule", "needs no fixing", "takes no lock". State the positive claim
when one exists. "Your sentence passes every rule" says what "breaks no rule"
meant. When the negation is the fact, write it in plain form, in its own
sentence: "This call does not take the lock."

Forms of be, have and do stay legal, since "the file has no header" is
ordinary.

## Only before the subject

"Only X does Y" means nothing but X does Y. It also moves the topic to the end
of the sentence, behind a subject the reader has to hold.

    // Only the indexer's cache spec carries the pool size.
    // The pool size is read from its canonical location in the indexer's cache spec.

The second leads with the topic and says where the value lives, which is the
positive form of "only". "only" on a verb ("Runs only on Linux") and a label
with no verb ("Only these URLs") are fine.

See [negation-foil](../negation-foil/rule.md) for a negation that follows a
positive claim.
