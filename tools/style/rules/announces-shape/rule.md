# Announced shape

A comment that announces the shape of its explanation makes the reader wait
for the content: "Two rules apply here.", "There are three things to
consider", "This section describes...". Delete the count and keep the list.
The reader can see how many items follow.

Delete the opening four words. If nothing was lost, the comment was an
announcement.

A markdown heading is a label, and announcing what follows is its job. This
rule judges prose and comments.

A lead-in that ends in a colon and introduces the list below it is a label:
"An endpoint value has one of these forms:". So are headings and numbered
steps.
