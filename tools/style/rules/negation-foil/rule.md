# Negation foil

Write the positive claim. If a negation is required, give it its own sentence.
A negation that cannot fill a sentence was not required.

That test replaces any judgement about whether a contrast is earned. The foil
shapes are "X, not Y", "X, never Y", "X and not Y", "X and never Y", "X
instead of Y" and "X rather than Y", all of them a finished claim followed by a
negated restatement of the same slot. Each one splits or goes.

    // A commit body says why, not what.
    // A commit body says why. The diff already says what.

The split earns its sentence, because "the diff already says what" is a fact
the reader did not have. Compare a negation that cannot fill one:

    // A fragment introducing a list takes a colon, not a full stop.
    // A fragment introducing a list takes a colon.

"Stage 3: era-specific" shows the rule better than any sentence about full
stops, so the foil goes.

"not just X but Y" and "it's not X, it's Y" still fail on sight, since both
conjure the misunderstanding they then correct.

On a public item, a negation becomes a caller obligation. See
[Public items](../../COMMENTS.md#public-items) in `COMMENTS.md`.
