# An element is `<Class|Class>`, a word, `(a|b)`, `!<X>` or `&<X>` for
# lookahead, `^`, `$`, or `[ a b | c ]`. A `*`, `+` or `?` may follow.
# Classes are in src/pattern.rs. object-first and causal-fragment misread
# verb-first doc comments, so they report leads.
