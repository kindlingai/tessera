# Verb at the end

"Bytes one element takes.", "Rows the pool holds.", "Ids the reply carries."
The real subject sits in a clause at the end, and the verb that relates it
comes last.

Lead with the subject, or name the quantity:

    /// Bytes one element takes.
    /// The size of one element, in bytes.

    /// Rows the pool holds.
    /// The pool's row count.

"take" as a noun stays legal: "since the last take".
